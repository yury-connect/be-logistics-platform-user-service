## Запуск `user-service`

```bash
# Сначала запустить инфраструктуру
docker-compose up -d

# Проверить что БД готова
docker exec -it logistics-postgres pg_isready -U postgres

# Запустить Spring Boot приложение
./mvnw spring-boot:run

# Или с конкретным профилем
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```
